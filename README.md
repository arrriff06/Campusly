# Campus Event Management & Feedback Analyzer

## Project Title

Campus Event Management & Feedback Analyzer

## Course

PBL - Problem Solving Using Python (MCA17400)

## Description

Campus Event Management & Feedback Analyzer is a Python-based console application developed to manage university events, student registrations and event feedback.

The system allows users to create and manage events, maintain student information, register students for events, prevent duplicate and over-capacity registrations, cancel registrations and collect feedback.

The collected feedback is analyzed using NumPy and Pandas. Matplotlib is used to generate charts for event ratings, rating distribution and event-wise participation.
